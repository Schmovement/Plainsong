# Plainsong phase features

## Phase 0
- Local library and playback, queue, web sources, equalizer, playback-speed controls, and A–B loop.

## Phase 1
- Versioned full-backup export, including binary data.

## Phase 2
- Restore with validation, preview, and round-trip support.

## Phase 3
- Metadata and custom-cover editing.

## Phase 4
- Five-star ratings, sorting and filtering, with likes preserved.

## Phase 5
- Dynamic smart playlists with a rule editor.
